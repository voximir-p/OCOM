# OCOM

## About

This repository is mainly used to share my code with others who are also interested in competitive programming.

## Why C?

You might have noticed that I use plain old C to write all this code. I'm not trying to _show off_; writing in C just helps you learn better.

But don't just take my word for it. Try it yourself! I ended up learning about circular queues and implementing one myself, which would never have happened if I had simply used C++ `std::queue`.

Plus, C compiles **blazingly fast**!

## My Setup

Some of you might also like to know what I use for coding, so here you go.

- **Zed** - My main code editor. It's **fast**! I won't be going back to VS Code.
- **cppu** - My custom C/C++ compiler and runner. It has even more features, too.
- **Arch Linux** - The OS I use. Linux is just better than Windows.
